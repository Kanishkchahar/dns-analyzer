Why some checks are unavailable, and how to enable them

The server decides which checks may run — this dashboard cannot override that policy. On your own deployment, set these variables and restart:

  • ENABLE_ACTIVE_PORT_SCAN=true plus PORT_SCAN_API_KEY and/or PORT_SCAN_ALLOWED_DOMAINS=example.com for active TCP checks and the extended port list. On a local run with no DNS_ANALYZER_API_KEYS configured, scanning is enabled automatically.
  • ENABLE_WIDE_DIRECTORY_SCAN=true plus WIDE_PATH_SCAN_API_KEY and/or WIDE_PATH_SCAN_ALLOWED_DOMAINS=example.com for the extended directory list.

Keep allowlists to domains you control. Without a key or allowlist the server still refuses active probes, by design.
